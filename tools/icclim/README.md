# Climate Indices Computation (icclim)

This tool computes climate indices from daily CF-compliant NetCDF files using
`icclim <https://icclim.readthedocs.io>`_ (v7). It covers all **ECA&D / ETCCDI**
temperature, precipitation and snow indices, and lets you define fully custom indices.

Multiple indices can be computed in a single job — click **"Add Index to Compute"**
to add more. All results are merged into one output NetCDF file.
